# Konstantin · Dein KI-Kompass

*Beständig orientiert in der Welt der KI.*

Unabhängige Orientierung bei der Auswahl von KI-Tools für Privatpersonen und Unternehmen: Empfehlung, Cloud-KI-Entscheidungsmatrix, Benchmark, Datenschutz-Ampel, Token- und Gesamtkostenrechner, Lernpfad „KI in der Cloud“, Glossar und der Chat-Assistent „Frag Konstantin“.

Ein Angebot von Nazan At · Mensch & KI byDesign.

## Inhalt

| Datei | Zweck |
|---|---|
| `index.html` | Die komplette Webseite (eine Datei, ohne Server lauffähig) |
| `logo-animation.html` | Logo-Animation als eigenständige Seite |
| `logo.svg`, `favicon.svg` | Bildmarke und App-Icon |
| `docs/konstantin-ki-kompass.md` | Alle Inhalte als Markdown |
| `n8n/` | Workflows für Datenaktualisierung, Chat-Endpunkt und Chat-Demo |

## Chat-Assistent aktivieren

In `index.html` die Production URL des n8n-Webhooks bei `KONSTANTIN_CHAT_ENDPOINT` eintragen. Zum Testen zuerst `n8n/konstantin-chat-demo-workflow.json` verwenden (ohne KI, ohne Kosten).
